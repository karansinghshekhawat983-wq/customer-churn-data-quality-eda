Customer Churn Data Quality and Exploratory Data Analysis (EDA)

Project Overview

This project focuses on analyzing customer churn data and identifying data quality issues through Exploratory Data Analysis (EDA).

Objectives

- Analyze customer churn patterns.
- Identify missing values and duplicate records.
- Perform data cleaning and quality checks.
- Explore relationships between customer features and churn.
- Generate insights from the dataset.

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Project Files

- "Customer_Churn_Data_Quality_and_EDA.ipynb"
- "customer-churn-data-quality-eda.zip"
